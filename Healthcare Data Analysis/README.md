# Heart Disease Risk Analysis

This project analyzes a heart disease dataset to identify key risk factors using Python, SQL, and Tableau.

## Tools Used
- Python (Data Cleaning & EDA)
- MySQL (Querying & Aggregation)
- Tableau (Interactive Dashboard)

## Dashboard Highlights
- Total Patients & Disease Rate %
- Risk by Gender and Age
- Risk by Chest Pain Type
- Cholesterol Distribution
- Cholesterol vs Max Heart Rate (Scatter Plot)
- Interactive Filters (Gender, Age Group, Chest Pain)

## Key Insight
Heart disease risk increases with age and varies significantly by chest pain type and clinical indicators such as cholesterol and maximum heart rate.

This project demonstrates end-to-end data analysis from data preparation to interactive visualization.
